A LITTLE CLARITY

Before
you begin.

Is Badilika really free?

Yes. There are no ads or paid tiers in this release. The original source is available under the MIT License, so you can inspect and contribute to it.

How do app limits work?

With Usage access and Accessibility enabled, Badilika totals daily usage and returns the selected app to Home at its limit. This is best effort; background playback can continue and Android can stop services.

Can I turn protection off?

Request a change, wait for the category's cooldown, then confirm. You can cancel the request to keep protection. Android settings can still revoke permissions or uninstall the app.

Does it block every explicit site?

No. Domain filtering can miss sites and cannot inspect content inside general apps. Other VPNs, proxies and encrypted DNS can bypass it. See the in-app setup guide for connection advice.

Will an update erase my timers?

Install the new APK over your existing Badilika installation. With the same package and signing key, settings remain in place. Uninstalling or clearing storage deletes local records.
