# Badilika - Desktop Adult & Escort Content Blocker (Windows)

**Badilika** (*Swahili for "Change" / "Transform"*) is an intentional, distraction-free desktop application designed to protect you from pornographic websites, adult tube sites, webcam services, explicit content, and escort/adult classifieds directories—**without breaking movie streaming platforms or everyday social media**.

---

## 🌟 Key Features

1. **Targeted Blocking (Zero Collateral Damage)**:
   - Blocks adult tube sites, webcam services, explicit paywalls, and escort/adult classifieds.
   - **Strictly Whitelisted**: Netflix, Amazon Prime Video, Disney+, Hulu, HBO/Max, YouTube, Reddit, X (Twitter), Instagram, LinkedIn, and Twitch remain 100% accessible.
2. **SafeSearch Enforcement**:
   - Enforces strict SafeSearch for Google, Bing, and DuckDuckGo at the system level so explicit thumbnails and previews are filtered out.
   - While protection is active, adds Windows Firewall guards for common public DNS, DNS-over-TLS and DNS-over-HTTPS resolver endpoints. The Home dashboard shows the current blocked-domain, custom-rule and resolver-guard counts.
3. **5-Hour Cool-Down Delay Safeguard**:
   - Clicking "Disable" does **not** turn off the blocker immediately.
   - Triggers an irrevocable **5-hour countdown** during which the blocker remains 100% active.
   - Allows you to cancel the unblock request at any time to re-lock immediately.
   - State persists across app restarts and computer reboots.
4. **Nature-Inspired Modern UI**:
   - Features the scenic misty forest mountain background.
   - Clean sidebar navigation (`Home`, `Rules`, `Settings`, `About`).
   - Anti-aliased vector icons (zero emojis).
5. **Seamless Updates & Desktop Icon**:
   - Includes a custom green leaf Windows icon.
   - Includes `Badilika-Setup.exe` installer/updater that places a shortcut right on your Desktop.
   - Future updates automatically detect your existing installation and ask to update without losing settings or lock states.

## Important limitation

This is a hosts-file based Windows blocker. It cannot inspect arbitrary encrypted browser DNS providers, VPNs, proxies, or direct-IP traffic. The common-resolver firewall guard reduces those bypasses but is not a claim of universal filtering.
